# Soroeru（揃える）

**あなたの情報を、あなたの手に。**

`Soroeru` は、あなたの個人情報をあなたのパソコンの中（ローカル）で暗号化して管理し、**世界中に
散らばったあなたの個人情報を「揃える」ためのローカルアプリ**です。

> このアプリは個人利用のためのツールです。個人情報は常にあなたのパソコンの中で暗号化して管理され、
> `Soroeru` のサーバーには保存されません（hosted vault なし・個人情報を含むテレメトリなし）。

> **方針転換（2026-06-25）.** 本プロジェクトは `Catashiro` から **`Soroeru`** へと、名前と要件
> から作り直しています。Soroeru は「自動でフォームを埋めるエージェント」ではなく、**個人情報・
> アカウント・オンライン契約というドメインで、あなた自身が「選べる力（自由意志）」を取り戻し、
> 育てていくための道具**です。詳しい製品方向は [`docs/requirements.md`](docs/requirements.md) を
> 参照してください。なお、リポジトリ／コードの識別子も `catashiro` から `soroeru` へ改名しました。

## 名前の由来

`Soroeru（揃える）` には、「世界中に散らばった個人情報を揃える」という意味を込めています。
世界中のユーザーが各自、自分のパソコンの中で自分の散らばった情報を揃えていく——その総体として
「個人情報が揃う」状態を目指します（中央に集約はしません）。

## Soroeru が目指すこと

多くの人にとって、次のことは「理論上はできる」のに「現実にはほぼできない」状態にあります——
面倒すぎる・複雑すぎる・時間がかかりすぎる・覚えていられないからです。

- 自分がどのサービスに、何の個人情報を渡したかを把握する
- 住所・電話番号・カード情報の変更を、登録済みの全サービスに反映する
- 不要なサービスから退会し、放置アカウントを減らす
- 不要なメルマガを止め、使っていないサービスの課金を止める

`Soroeru` は、この「形だけの選択肢」を「実際に選べる選択肢」に変えます。そして、あなたが
**だんだん自分で判断できるようになっていく**ことを大切にします（`Soroeru` が代わりに選ぶのではなく、
あなたが選べるようになることがゴールです）。

## 最初にできること（可視化）

1. Google / Chrome のパスワードマネージャーから書き出した CSV（サイト名・URL・ユーザー名・
   パスワード・メモ）を `Soroeru` に取り込みます。
2. `Soroeru` が各サイトにあなたの資格情報で自動ログインし、登録済みの個人情報を集めて
   **一覧（台帳）** を作ります。
3. 「どのサイトに、何を、いつ渡したか」が一望でき、**古い電話番号・住所・カード**が登録された
   ままのサイトが見えるようになります。
4. **メルマガ購読中のサイト**・**課金中のサイト**で絞り込めるので、不要なメルマガ停止や使って
   いないサービスの課金停止が、ぐっと身近になります。

その後、**一括更新**（古い情報を最新へ揃える）、**退会・整理**、**新規登録**の順に広げていきます。

## 確認と安全の仕組み

`Soroeru` はあなたの代わりに手間のかかる作業（雑務）を引き受けますが、**何を渡し、何を拒み、
何を残すかという「判断」はあなたのもの**です。

- **委任の段階**: 既定は「毎回確認」。あなたが理解を示した操作だけ「方針内は自動・例外のみ確認」へ、
  あなた自身の操作で広げられます。**任せる範囲をいつでも即座に狭められます。**
- **必ずあなたが決めること（自動化しない）**: 高リスクな規約（自動更新サブスク・強制仲裁・第三者
  提供など）／支払い／「18歳以上」などの本人性チェック／`Soroeru` 内に保存したデータの削除。
- **CAPTCHA・二段階認証・本人確認**: これらは突破しません。同じブラウザ画面であなたに操作をお願いし、
  完了したら続きから自動で再開します。
- **規約が自動アクセスを禁じている場合**: 勝手にブロックせず、注意点として知らせ、**あなたが判断**します。

## このアプリでしないこと

- CAPTCHA・二段階認証・bot 検知・アクセス制限の**突破**（検知してあなたに引き継ぐだけです）
- 他人のデータの収集
- 決済・購入（無料トライアル→課金のカード入力を、あなたが承認した場合のみ例外）
- 個人情報を含むテレメトリの送信
- `Soroeru` 自身のクラウドサーバーでの個人情報の保存
- あなたの明示的な同意なしに個人情報を AI に送ること（Chrome 拡張版）

## セキュリティとプライバシー

- 個人情報・**クレジットカード（セキュリティコード含む）**・**各サイトの ID／パスワード**・API キーは、
  すべて**ローカルで暗号化**して保存します（AES-256-GCM。マスターパスフレーズから鍵を導出）。
- 取り込んだパスワード CSV は直ちに暗号化し、ログには残さず、処理後に安全に破棄します。
- 自動ログインで集めた個人情報は外部に送らず、ローカルで暗号化して保存するだけです
  （Chrome 拡張版で、あなたが明示的に同意した Gemini 読み取りを除きます）。
- サイトのパスワードとカードのセキュリティコード（CVV）は、ローカルで暗号化して保存しますが、
  どの AI にも送りません（対応中: Issue #572）。情報収集のためのログインでは、保存済みのパスワードを
  `Soroeru` のプログラムが入力します。それ以外（登録・更新フォームのパスワード、カード入力の CVV）
  では一時停止し、Chrome の自動入力（パスワードマネージャー・お支払い方法）の候補をあなたが選びます。
- 鍵はアンロック中のみメモリ上にあり、ロックや終了で破棄します。リカバリキーを発行します。
- AI には**フォームの構造や規約の文章**を渡しますが、**実際の個人情報の値は渡さず、ローカルで処理**します
  （Chrome 拡張版で、あなたが明示的に同意した Gemini 読み取りを除きます）。

### Chrome 拡張版（開発中）での 4 つの区分

Chrome 拡張と Google Cloud を組み合わせた新しい構成（Issue #554）では、情報を次のように分けます。

1. **ローカル保存**: 個人情報・パスワード・カード情報・開示台帳は Chrome 内で暗号化して保存します。
2. **共有フォーム知識（個人情報なし）**: 「この入力欄は郵便番号」といった画面構造と項目の対応だけを
   Google Cloud で共有し、利用者全員の精度向上に使います。
3. **改善用の動作データ（個人を特定しない）**: 成功・失敗・手動引き継ぎなどの結果だけを、決められた
   項目に限って送ります。値・ページ内容・利用者の識別子は送りません。本番前に停止設定を用意します。
4. **同意したときだけの Gemini 読み取り**: 構造だけでは読み取れないときに限り処理を止めて確認し、
   「今回だけ送信する」を選んだ場合だけ、必要な部分を Gemini に送ります。パスワードやセキュリティ
   コードは送りません。送った内容は改善用データとして保存しません。

詳しくは [`docs/user-manual.md`](docs/user-manual.md) の「プライバシーとセキュリティ」を参照してください。

## 想定している利用者

多数のサイトに個人情報を登録済みで、その全体像を把握し、更新・退会・整理を自分の手で繰り返したく
ない人。自分の個人情報を第三者のサービスに預けず、自分のパソコンの中で管理したい人。

## 現在の開発状況

本プロジェクトは `Catashiro` から `Soroeru` への**再設計（要件定義）段階**にあります。製品方向は
[`docs/requirements.md`](docs/requirements.md) が正典です。技術スタック（言語・シェル・自動化・
ストレージ）は要件確定後に**0 ベースで**決め直します。

ブラウザ操作の主経路は、ユーザーが明示的に選んだ実ブラウザのタブを操作する
Soroeru Chrome 拡張へ段階的に移行します。Playwright は移行後、開発テスト用途だけに
残す方針です。対象ロケールは当面**日本語サイトのみ**です。
