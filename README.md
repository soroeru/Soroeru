# Catashiro

`Catashiro` は、あなたの個人情報をあなたのパソコンの中（ローカル）で暗号化して管理し、**AI エージェントが
あなたの代わりに Web サイトへの会員登録や登録情報の更新を自動で行う**ローカルアプリです。

URL を渡すと、AI エージェントがそのサイトの登録ページを見つけ、保存済みの情報を入力し、あなたが内容を
1回確認したうえで登録まで自動で完了します。

> このアプリは個人利用のためのツールです。ブラウザ操作には Playwright を使い、Chrome だけでなく
> Firefox / Safari 系エンジンでも動くことを目指します。

## 名前の由来

`Catashiro` は、日本の神道で人の代わりに祓いを受ける人形「**形代（かたしろ）**」の頭文字を
K → C に変えた名前です。「自分の代わりに何かをしてくれる存在」という形代のイメージに、
C にしたことで連想される **cat（猫）** の可愛らしさを重ね、「猫があなたの代わりにサイト登録
などをしてくれる」イメージを込めています。将来的に猫をモチーフにしたアイコンも検討しています。

## このアプリは何をするものですか？

- あなたの個人情報（氏名・住所・電話番号・メール・クレジットカード・各サイトの ID／パスワードなど）を
  **ローカルに暗号化して保存**します。
- **新規登録**: 登録したいサイトの URL を渡すと、AI が登録ページを探し、フォームに入力し、内容確認のうえ
  登録まで自動で行います。保存されていない項目があれば、その場であなたに入力をお願いし、次回以降のために
  保存します。
- **一括更新**: 引っ越しや電話番号の変更などで情報が変わったとき、登録済みのサイトを選んで「最新の情報に
  アップデート」すると、各サイトの古い情報との差分を見つけて更新します。
- どのサイトに何を登録したかを一覧で確認できます。

## 使い方

1. `Catashiro` にマスターパスフレーズを設定し、自分の個人情報を登録します（暗号化して保存されます）。
2. 利用する AI（Anthropic の Claude、または OpenAI の GPT）の API キーを設定画面で入力します。
   ※ AI はあなた自身が契約しているものを使います。
3. 登録したいサイトの URL を渡します。
4. AI が登録ページを見つけ、フォームに入力します。足りない情報があれば入力を求められます。
5. **「このサイトに登録します。よろしいですか？」という確認**が表示されます。送信される内容・規約・注意点
   （後述の高リスク項目）を確認できます。
6. あなたが承認すると、AI が規約同意と登録の送信まで自動で行います。
7. 登録済みの情報を変更したいときは、保存している情報を更新し、対象サイトを選んで一括更新します。

## 確認と安全の仕組み

`Catashiro` は自動で登録を進めますが、**あなたが承認するまで送信はしません**。また、次のような場面では
無理に自動化せず、安全側に倒します。

- **高リスクな規約の警告**: 自動更新サブスク、強制仲裁、第三者へのデータ提供などの条項を見つけたら、
  確認画面で知らせます。長くて読み飛ばしがちな規約のリスクに気づけるようにするためです。
- **支払いは原則行いません**: 決済・購入は対象外です。ただし「無料トライアル後に課金が始まる」登録は、
  高リスクとして確認し、あなたが承認した場合だけカード情報を入力します。
- **資格・本人性の確認**: 「18歳以上」「在住」などのチェックは、あなた自身に確認します（自動でチェック
  しません）。
- **自動登録が禁止されているサイト**: 入力までは行いますが、最後の登録ボタンはあなたが押します。
- **CAPTCHA・二段階認証・本人確認・確認メール**: これらは突破しません。同じブラウザ画面であなたに操作を
  お願いし、完了したら AI が続きから自動で再開します。

## このアプリでしないこと・できないこと

- CAPTCHA・二段階認証・bot 検知・アクセス制限の**突破**（検知してあなたに引き継ぐだけです）
- 決済・購入（上記の無料トライアル→課金のカード入力を除く）
- 自動登録が禁止されたサイトでの自動送信
- あなたが設定した AI プロバイダ以外への情報送信、テレメトリ送信
- `Catashiro` 自身によるクラウドサーバーでのデータ保存（データは常にあなたのパソコンの中で暗号化して
  管理されます）

## セキュリティとプライバシー

- 個人情報・**クレジットカード（セキュリティコード含む）**・**各サイトの ID／パスワード**・API キーは、
  すべて**ローカルで暗号化**して保存します（AES-256-GCM。マスターパスフレーズから鍵を導出）。
- 鍵はアプリのアンロック中（ロック解除中）のみメモリ上にあり、ロックや終了で破棄します。保存はしません。
  パスフレーズを忘れた場合に備えてリカバリキーを発行します。
- AI には**フォームの構造や規約の文章**を渡しますが、**実際の個人情報の値は渡さず、ローカルで入力**します。
- セキュリティコード（CVV）は最も機微な情報として扱い、入力する瞬間だけ復号して直ちに破棄します。
- 個人情報を扱う重要なサイトでは、登録・更新の内容を必ず確認してください。

## 想定している利用者

多数のサイトに登録があり、新規登録や、引っ越し・連絡先変更に伴う更新を、自分の手で繰り返したくない人。
自分の個人情報を第三者のサービスに預けず、自分のパソコンの中で管理したい人。

## 現在の開発状況

このプロジェクトは方針転換を経て初期開発段階にあります。まずは実在サイトを使わず、ローカルのテスト
サイトで「登録」と「情報更新」を検証する PoC から進めます。設計の詳細は
[`docs/rfc/rfc-001-chrome-autofill-pivot.md`](docs/rfc/rfc-001-chrome-autofill-pivot.md) を参照してください。

最初の MVP は **Mac 専用デスクトップアプリの private beta** として、既知の初期ユーザー約10名に絞って
検証します。対象は Apple Silicon Mac の macOS 14 Sonoma / macOS 15 Sequoia です。Windows / Linux /
モバイルアプリ / ブラウザ拡張としての配布は MVP では扱いません。

MVP で beta ユーザーが完了できるべき最小ワークフローは、初回セットアップ、個人情報管理、サイト追加
（新規登録または既存アカウント取り込み）、確認ゲートつき登録、登録済みサイト一覧、一括更新、退会タスク
準備、ユーザーマニュアルとダウンロード導線です。詳しいスコープと成功基準は
[`docs/requirements.md`](docs/requirements.md) の「MVP And Private Beta Target」を参照してください。
