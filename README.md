# Soroeru（揃える）

**あなたの情報を、あなたの手に。**

Soroeru は、各サービスに登録した個人情報を一覧にまとめ、更新や退会を進めるためのツールです。
Chrome 拡張内で情報を暗号化して保存し、Google Cloud の共有フォーム知識を使って収集を支援する構成を開発しています。
利用者が選んだ作業をまとめて進め、判断が必要な場面で確認することを目指します。

## 現在使える範囲

開発版の Side Panel で、暗号化 vault の作成と解錠、架空サイトの登録、選択した Chrome タブからの情報収集を試せます。
クラウド支援を有効にすると、共有スキーマとフォーム構造だけを使う Gemini の対応付けを利用できます。
未解決の項目は不明として残します。

設定画面ではクラウド支援と改善データ共有を別々に管理できます。どちらも既定でオフです。改善データの送信は、対応する Cloud API が有効になるまで保留キューに保存されます。
個人情報を Gemini に送る同意付き読み取りと全画面の移植は未完了です。
一括更新、退会、新規登録は可視化の後に提供する方針で、現行拡張の機能として案内していません。
旧 Mac 版は移行元としてコードに残っています。

## 情報の扱い

- 個人情報とパスワードはローカルで暗号化して保存します。
- クラウド支援と改善データの共有は別々に選び、既定ではオフです。
- オフにすると未送信の共有データを破棄し、新しい送信を止めます。
- 現行拡張の Gemini 対応付けには値を送りません。
  将来の同意付き読み取りでも、送るサイトと情報の種類を先に示します。
- パスワードとカードのセキュリティコードは、どの AI にも送りません。
- CAPTCHA や二段階認証などでは同じタブで利用者に操作を引き継ぎます。
- 課金や不可逆な削除など、結果を伴う判断には確認を残します。

保存と復旧、開発版の制限は[利用者向けガイド](docs/user-manual.md)を参照してください。
拡張のビルドと読み込みは[開発手順](docs/development.md)、製品の目標は[要求](docs/requirements.md)に記載しています。
