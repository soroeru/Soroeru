## 共有ファイルの調整

各 Issue は `scripts/issue-worktree.sh` で作る専用 worktree を使用する。
`src/shared/cloud-contract.ts`、`ResolutionOrchestrator`、`cloud/package.json`、ロックファイル、
`docs/development.md` を変更する前に、相手の Issue と変更箇所・契約を合わせる。
先行 PR の契約を再利用し、担当外の業務ロジックを同時に実装しない。

#559 は API 契約、スタブ、予算・チケットの安全境界、デプロイ基盤を所有する。
#560〜#563・#566 は対応するスタブを業務ハンドラへ置き換える。
#564 はクラウド SDK、拡張への認証情報混入、禁止送信先などの静的検査を拡充する。
#559 の `soroeru-cloud` 注釈対応は CloudClient を既存検査で認識するための最小変更に限る。

本番の既定値、センシティブなサイトカテゴリの昇格可否、Gemini モデル ID、直接保存アダプタの採否は
各 Issue の未決事項として扱い、担当者の推測で確定しない。
