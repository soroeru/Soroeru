# Issue Implementation Plan Template

Use this template when writing an implementation plan in a GitHub Issue.
Remove sections that do not apply.

```md
## Implementation Plan

### Goal
- What this Issue should solve

### Scope
- Work included in this Issue

### Non-Scope
- Work intentionally left out

### Approach
- Which layers or modules change
- Existing code or documents to reuse
- Rules, branching, or migration strategy

### Files / Directories
- Main files or directories expected to change

### Verification
- Format / lint / test commands
- Manual checks

### Risks
- Expected regressions or hard parts

### Open Questions
- Decisions still needed before implementation
```

Minimal version:

```md
## Implementation Plan
- Goal:
- Scope:
- Approach:
- Verification:
- Open Questions:
```
