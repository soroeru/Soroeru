# Soroeru 開発版の利用ガイド

現在の Chrome 拡張は開発者向けの可視化デモです。
ローカルに暗号化した vault を作り、選択したタブから情報を読み取れます。
一括更新、退会、新規登録はまだ利用できません。
個人情報を Gemini に送る読み取りは、収集中に範囲を確認して承認した場合だけ使えます。
検証には架空のデータを使ってください。

## 初回の利用

1. [開発手順](development.md#run-the-extension)に沿って拡張をビルドし、Chrome に読み込みます。
2. ツールバーから Soroeru の Side Panel を開き、パスフレーズを設定します。
3. 一度だけ表示されるリカバリーキーを安全な場所に控え、暗号化エクスポートも保存します。
4. 架空のサイトを追加して対象の HTTPS タブを選び、そのサイトへのアクセスを許可します。
5. 収集を開始し、台帳で結果と不明な項目を確認します。

パスフレーズを忘れた場合は、リカバリーキーで既存の vault を開きます。
ブラウザのデータ削除や拡張の削除で vault 自体を失った場合、キーだけでは復旧できません。
暗号化した控えも必要です。

## 暗号化バックアップと復元

解錠後の「暗号化エクスポートを保存」で保存先を選びます。
保存先の選択に対応していないブラウザでは「ダウンロード」を押し、ファイルを保存できたことを確認してから「ファイルを保存できました」を押してください。
キャンセルや保存失敗ではバックアップの案内が残ります。バックアップはその時点の控えで、自動更新されません。
ブラウザのプロファイルとは別の安全な場所に保管してください。平文のエクスポートは作りません。

別のプロファイルやデータ消失後は、初期設定画面の「暗号化バックアップを取り込む」で JSON ファイルと元のパスフレーズを指定します。
既存データを置き換える場合は先にエクスポートして施錠し、全データを置き換える確認にチェックします。チェックしなければ置き換えません。
壊れたファイル、誤ったパスフレーズ、未対応の形式・レコードバージョンは取り込まず、以前のデータを保持します。
取り込み後は元のパスフレーズで解錠し、内容を確認してください。元の控えは確認が終わるまで保管します。

## 収集が止まった場合

CAPTCHA、二段階認証、アクセス制限がある場合は、同じタブで操作を引き継ぎます。
自動アクセスを禁じる規約を検出した場合も注意点を表示します。
制限を回避する操作は行いません。

ページの変更や通信失敗で読めない情報は、不明として残します。
タブの変更、権限の取り消し、施錠、パネルを閉じる操作で実行が中断します。
再開時は対象のタブを選び直して状態を確認します。
保存に失敗した場合はエラーを確認し、再試行か暗号化エクスポートを行ってください。

## クラウド支援と情報の共有

クラウド支援と改善データ共有は、Side Panel の「クラウドと共有の設定」で個別に管理します。どちらも既定でオフです。
「クラウドのフォーム知識と Gemini を使う」を有効にすると、共有フォーム知識を取得し、必要に応じて Gemini にフォーム構造だけを使った項目の対応付けを依頼します。
現在の経路ではフォームの構造だけを送り、値は Chrome 内で読み取ります。
クラウドを使わない場合も、台帳と利用できるキャッシュは残ります。

「改善用の動作データを送る」はクラウド支援とは別の設定です。
有効にすると、値を含まない対応付けを暗号化キューに保存します。クラウド支援も有効な場合に限り配送します。
どちらかをオフにすると未送信データを破棄します。識別用キーの再生成も未送信の対応付けを破棄します。送信済みデータは取り消されません。
個人情報、ページ本文、パスワードを改善データとして送ることはありません。

設定画面では、端末内の暗号化保存、共有フォーム知識、任意の改善データ、別途同意した場合だけの Gemini 読み取りについて説明します。
クラウド接続先がないビルドでも設定を確認できますが、クラウド機能は利用できません。

未解決の項目が残ると、対象サイト、ページの種類、情報の種類、送信先、16 KiB の上限、秘密情報の除外、改善用に保存しないことを示して承認を求めます。
選択肢は事前に選ばれません。「この1回だけ送信する」か、ページの種類が分かるときだけ「この収集だけ許可する」を選べます。
収集単位の承認は、表示したサイト・ページの種類・属性に限り、最大 20 件、承認から 15 分です。
同じ収集の同じ範囲では確認を繰り返しません。範囲が変わる、期限が切れる、壁で引き継ぐ、施錠する、パネルを閉じる、送信を止めると承認は無効になり、再開後は新しい承認が必要です。
「送信しない」、閉じる、5 分の無操作では何も送らず、手動の収集を続けられます。
収集中は「Gemini への送信を止める」で残りの承認を取り消せます。
パスワードとセキュリティコードは対象に含めず、送った個人情報を改善用に保存しません。

## 旧 Mac 版からの移行

旧 Mac 版で保存した Vault v2 の暗号化エクスポートを、上の手順で拡張に取り込めます。
Argon2id と PBKDF2 の両方に対応します。旧 v1 ファイルはこの画面では取り込めません。
元の vault を削除せず、拡張で内容とリカバリーキーを確認してから移行を判断してください。
拡張デモを使うために旧アプリや Native Messaging host を起動する必要はありません。
旧版の AI 収集は利用者が設定したプロバイダに秘密以外のページ情報を送る経路があり、現行拡張とは異なります。

### 本人確認なしで自分の情報を編集する

vault を解除すると「自分の情報」で氏名・住所・連絡先などを保存できます。
JPKI や電話・メールの OTP は、このローカル編集や可視化の開始条件ではありません。
サイト自身の認証は、そのサイトのタブで行ってください。
手入力は「ユーザー入力・未検証」、旧データは「出所不明・未検証」と表示します。
検証済みの値を変更して保存した場合も未検証になります。
保存に失敗した入力は未保存のまま残り、台帳の正典は直前の値を維持します。
カード・パスワード・CVV はこの編集画面には表示しません。

「収集の自動実行範囲」でサイトと項目を選び、L1 を明示的に有効にできます。
初回に選択済みの対象はありません。クイズや承認回数の条件もありません。
選択を外すとすぐに実行を止め、追加は有効化ボタンで保存するまで適用しません。
「L1 を停止する」は実行中も使えます。保存に失敗した場合は停止を維持し、
保存の再試行または暗号化バックアップを案内します。
実行には「収集」で選択したタブのアクセス許可が引き続き必要です。
L1 は読み取りの範囲であり、AI への個人情報送信や支払い・退会・本人性の表明を許可しません。
壁で停止した後は同じタブで確認し、「再開」で新しい実行権限を取得します。

旧 vault の属性・権限レコードは解除時に移行します。旧 L1 は L0 になります。
移行の保存に失敗した場合は元の暗号化データを保持し、解除を完了しません。
移行後の属性・権限レコードは以前のビルドでは開けません。更新前のバックアップを保管してください。
