## 1. インストールと初回起動

### 1.1 アプリの入手

ベータ版は招待された方にのみ提供されます。招待メールに記載されたリンクから
`Catashiro-mac-beta.zip` をダウンロードしてください。

### 1.2 インストール手順

1. ダウンロードした `Catashiro-mac-beta.zip` を展開します。
2. `Catashiro.app` を `/Applications` フォルダに移動します。

### 1.3 初回起動時の Gatekeeper 警告について

現在のベータ版は Apple の公証（Notarization）を受けていないため、
初回起動時に macOS が警告を表示します。

**起動方法**:

1. Finder で `/Applications/Catashiro.app` を **右クリック**（または Control キーを押しながらクリック）します。
2. メニューから「**開く**」を選択します。
3. 「このアプリケーションはAppleによってチェックされていません」という警告が表示されます。
4. 「**開く**」をクリックします。

> この操作は初回のみ必要です。2 回目以降は通常通りダブルクリックで起動できます。

### 1.4 初回起動画面

初めて起動すると、ボルト（暗号化された個人情報の保管庫）のセットアップ画面が表示されます。
ブラウザで `http://127.0.0.1:4333/` が自動的に開きます（開かない場合は手動でアクセスしてください）。

## 2. ボルト（金庫）のセットアップ

ボルトは、あなたの個人情報を暗号化して保存するローカルの「金庫」です。

### 2.1 マスターパスフレーズの設定

1. セットアップ画面で「**新しいボルトを作成**」を選択します。
2. **マスターパスフレーズ**を入力します。

**マスターパスフレーズに関する重要事項**:

- 12文字以上の長さを推奨します。覚えやすく、かつ推測されにくいフレーズを使ってください。
- このパスフレーズはどこにも保存されません（Catashiro のサーバーにも送信されません）。
- **パスフレーズを忘れると、保存した個人情報にアクセスできなくなります。**

### 2.2 リカバリキーの保存

マスターパスフレーズを設定すると、**リカバリキー**が表示されます。

> **[画像プレースホルダー: リカバリキー表示画面]**

**リカバリキーについて**:

- 表示されたリカバリキーをコピーし、安全な場所に保存してください。
  （例: パスワードマネージャー、印刷して鍵のかかる場所に保管）
- リカバリキーを使うと、パスフレーズを忘れた場合でもボルトを復元できます。
- リカバリキーはこの画面以降は表示されません。必ず保存してから「確認した」をクリックしてください。

### 2.3 ボルトの場所

ボルトのデータはデフォルトで以下に保存されます：

```
~/Library/Application Support/Catashiro/vault.enc
```

設定画面から保存場所を変更することもできます。

### 2.4 ロック・アンロック

**ロック（画面ロック）**: アプリ上部の「🔒 ロック」ボタンをクリックするか、
アプリを終了するとボルトがロックされます。個人情報はメモリから削除されます。

**アンロック（画面ロック解除）**: アプリ起動時またはロック後にマスターパスフレーズを入力します。

> **セキュリティのヒント**: 席を離れるときはアプリをロックするか終了してください。

## 3. 個人情報の登録

ボルトのセットアップ後、「**個人情報**」タブから情報を登録します。

### 3.1 基本項目

以下の項目を登録できます（すべて任意ですが、多く登録するほど自動入力率が上がります）：

| カテゴリ | 項目例 |
|----------|--------|
| 氏名 | 氏名（漢字）、氏名（ふりがな）、氏名（ローマ字） |
| 連絡先 | メールアドレス、電話番号 |
| 住所 | 郵便番号、都道府県、市区町村、番地、建物名 |
| 勤務先 | 会社名、部署名 |
| クレジットカード | カード番号、有効期限、カード名義人、セキュリティコード（CVV） |
| サイト認証情報 | 各サイトのログイン ID・パスワード |

> **セキュリティコード（CVV）について**: セキュリティコードは特に慎重に扱われます。
> 入力が必要な瞬間だけ復号して使用し、その後すぐにメモリから削除されます。
> AI モデルには送信されません。

### 3.2 情報の追加方法

1. 「**個人情報**」タブを開きます。
2. 各カテゴリの「**＋ 追加**」ボタンをクリックします。
3. 値を入力して「**保存**」をクリックします。

### 3.3 フォームに必要な項目が足りないとき

サイト登録時に保存されていない項目が必要になった場合、Catashiro がその場で入力を求めます。
入力した値は次回のために自動的に保存されます。

## 4. サイトの追加（新規登録・既存アカウントの取り込み）

「**サイトを追加**」機能で、新しいサイトへの登録と既存アカウントの取り込みができます。

### 4.1 新規登録

1. 「**サイトを追加**」をクリックします。
2. 登録したいサイトの URL を入力します（例: `https://example.com`）。
3. 「**新規登録**」を選択します。
4. Catashiro がサイトの登録ページを探し、フォームを解析します。

> **[画像プレースホルダー: サイト URL 入力画面]**

5. 登録内容の確認画面（**確認ゲート**）が表示されます（[第5章](#5-確認ゲートと安全の仕組み)参照）。
6. 内容を確認して「**登録する**」をクリックすると、自動で登録が完了します。

### 4.2 既存アカウントの取り込み（インポート）

すでにそのサイトにアカウントを持っている場合は、「**既存アカウントを取り込む**」を選択します。

1. サイトの URL を入力します。
2. 「**既存アカウントを取り込む**」を選択します。
3. そのサイトで使っているログイン ID・パスワードを入力します。
4. Catashiro がアカウント情報をボルトに保存し、サイト一覧に追加します。

## 5. 確認ゲートと安全の仕組み

**確認ゲート**は、Catashiro が送信を行う前に必ず表示される確認画面です。
あなたが「登録する」をクリックするまで、フォームへの送信は行われません。

> **[画像プレースホルダー: 確認ゲート画面]**

### 5.1 確認ゲートに表示される内容

- **送信される情報の一覧**: どのフォーム項目に何が入力されるか
- **利用規約・プライバシーポリシーのリンク**
- **高リスク項目の警告**（あれば）

### 5.2 高リスク項目の警告

以下のような条件がある場合、確認画面で警告が表示されます：

| 高リスク項目 | 例 |
|------------|-----|
| 自動更新サブスク | 「無料期間終了後、月額 980 円が自動請求されます」 |
| 強制仲裁条項 | 「紛争は裁判ではなく仲裁で解決します」 |
| 第三者へのデータ提供 | 「パートナー企業と情報を共有することがあります」 |
| コンテンツライセンス | 「投稿したコンテンツを弊社が利用する権利を付与します」 |

これらの項目がある場合、確認が必要です。承認しないと登録は進みません。

### 5.3 自動では行わないこと

以下の項目はあなた自身に確認をお願いします（自動でチェックしません）：

- 「18歳以上です」などの年齢確認チェックボックス
- 「日本在住です」などの居住地確認
- 「この情報の送付を承認します」などの本人性確認

### 5.4 支払い・決済フォームの扱い

支払いフォームが含まれている場合、Catashiro は自動入力を停止します。
ただし「無料トライアル後に有料になる」登録については、高リスク項目として表示し、
あなたが承認した場合のみカード情報を入力します。

### 5.5 自動登録が禁止されているサイト

利用規約で自動での会員登録が禁止されているサイトでは、
フォームへの入力まで行いますが、最後の送信ボタンはあなたが押してください。
Catashiro がその旨を表示します。

## 6. 自動化できない場面での手動対応

以下の状況は自動化できません。Catashiro は検知して、同じブラウザ画面でバトンをあなたに渡します。

| 状況 | Catashiro の動作 |
|------|----------------|
| CAPTCHA | 「CAPTCHA が表示されました。解決してください」と案内し、待機します |
| 二段階認証（MFA / OTP） | 認証コードの入力を促し、待機します |
| SMS・メール認証 | 「確認コードを入力してください」と案内し、待機します |
| 本人確認 | 「本人確認の操作をしてください」と案内し、待機します |

**操作手順**:

1. Catashiro の案内が表示されます。
2. 同じブラウザウィンドウで、求められた操作（CAPTCHA の解決、認証コードの入力など）を行います。
3. 操作が完了したら Catashiro 上の「**完了 → 再開**」ボタンをクリックします。
4. Catashiro が続きから自動で再開します。

> **重要**: Catashiro は CAPTCHA の突破や二段階認証の回避は行いません。
> これらはセキュリティ保護のために存在するものであり、あなた自身が対応してください。

## 7. 一括更新

引っ越しや電話番号・メールアドレスの変更など、個人情報が変わったときに使います。

### 7.1 一括更新の手順

1. 「**個人情報**」タブで最新の情報に更新します。
2. 「**一括更新**」タブを開きます。
3. 更新したいサイトを選択します（チェックボックスで複数選択可）。
4. 「**差分を確認**」をクリックすると、変更前・変更後の差分が表示されます。
5. 内容を確認して「**更新を開始**」をクリックします。
6. 各サイトごとに確認ゲートが表示されます。内容を確認して「**更新する**」をクリックします。

> **[画像プレースホルダー: 一括更新画面]**

## 8. サイト一覧と登録状況の確認

「**サイト一覧**」タブで、Catashiro が管理しているサイトと登録状況を確認できます。

### 8.1 表示される情報

| 項目 | 説明 |
|------|------|
| サイト名・URL | 登録済みのサイト |
| 最終更新日 | 最後に情報を登録・更新した日付 |
| 登録した項目 | 送信した情報の種類（実際の値は表示しません） |
| ステータス | 最新 / 要更新 / 退会準備中 |

### 8.2 退会の準備

退会を検討しているサイトは「**退会準備**」として登録できます。

1. サイト一覧でサイトを選択します。
2. 「**退会を準備する**」をクリックします。
3. Catashiro が退会手順の確認を行います。
4. 最終的な退会操作（不可逆な操作）は、あなたが明示的に確認してから実行されます。

## 9. サポートバンドル（問題報告）

問題が発生した場合、サポートバンドルを作成して報告できます。

### 9.1 サポートバンドルの作成

1. 設定画面またはエラー表示から「**サポートバンドルを作成**」をクリックします。
2. バンドルファイル（`catashiro-support-YYYY-MM-DD.zip`）がダウンロードフォルダに保存されます。

### 9.2 サポートバンドルに含まれる情報

- アプリのログ（動作の記録）
- システム情報（macOS バージョン、アーキテクチャ）
- エラーメッセージ

**含まれない情報**:

- 個人情報の実際の値
- マスターパスフレーズ・リカバリキー
- クレジットカード情報
- ログイン ID・パスワード

> バンドルを共有する前に、内容をテキストエディタ等で確認することを推奨します。

## 10. アンインストールとデータの削除

### 10.1 アプリのアンインストール

1. アプリを終了します。
2. `/Applications/Catashiro.app` をゴミ箱に移動します。

### 10.2 個人データの削除

アプリをアンインストールしただけでは、ボルトのデータは残ります。
個人データを完全に削除するには、以下のフォルダを削除してください：

```
~/Library/Application Support/Catashiro/
```

**削除手順（Finder を使う場合）**:

1. Finder を開きます。
2. メニューバーの「**移動**」→「**フォルダへ移動**」を選択します。
3. `~/Library/Application Support/Catashiro/` と入力して「移動」をクリックします。
4. 表示されたフォルダをゴミ箱に移動します。
5. ゴミ箱を空にします。

> **注意**: この操作は元に戻せません。リカバリキーを持っていても、
> 削除したデータを復元することはできません。

## 11. プライバシーとセキュリティについて

### 11.1 データの保存場所

あなたの個人情報は **あなたのパソコンの中にのみ** 保存されます。
Catashiro のサーバーやクラウドサービスには保存されません。

### 11.2 暗号化

保存データはすべて **AES-256-GCM** という強力な暗号化方式で暗号化されます。
マスターパスフレーズから導出された鍵を使って暗号化・復号を行います。
鍵はアプリがアンロックされている間のみメモリ上にあり、ロックや終了で消去されます。

### 11.3 AI モデルへの情報開示

Catashiro は AI（Claude や GPT）を使ってフォームの構造を解析しますが、
**実際の個人情報の値（氏名・住所・カード番号など）は AI に送信しません**。
フォームの構造（どんな入力欄があるか）と規約の文章のみを送ります。
フォームへの実際の入力はあなたのパソコン上でローカルに行われます。

### 11.4 外部への通信

Catashiro が通信する相手は以下のみです：

1. あなたが登録・更新を指示した **対象サイト**
2. あなたが設定した **AI プロバイダ**（Anthropic / OpenAI）

テレメトリ、分析、クラッシュレポートなど、その他の外部サービスへの通信は行いません。

### 11.5 AI プロバイダの API キー

AI プロバイダの API キーは、個人情報と同じ暗号化方式でローカルに保存されます。
Catashiro には独自の AI サービスはなく、あなた自身が契約しているプロバイダを使います。

## 12. よくある質問

**Q: パスフレーズを忘れてしまいました**

A: リカバリキーを使ってボルトを復元できます。設定画面の「パスフレーズを忘れた場合」
から手順を確認してください。リカバリキーも紛失した場合は、残念ながらデータの復元は
できません。新しいボルトを作成する必要があります。

---

**Q: どの AI プロバイダを使えますか？**

A: 現在は **Anthropic（Claude）** と **OpenAI（GPT）** に対応しています。
設定画面で API キーを入力してください。AI を使わない場合も、基本的な機能は
使用できます（登録フォームの解析精度は下がる場合があります）。

---

**Q: クレジットカード情報を登録しても安全ですか？**

A: カード情報はすべてローカルで暗号化して保存されます。
セキュリティコード（CVV）はフォームへの入力直前にのみ復号し、入力後すぐにメモリから削除します。
AI モデルには一切送信しません。ただし、カード情報の保管は自己責任であることをご理解ください。
心配な場合はカード情報を登録せず、必要な場合のみ手動で入力することをお勧めします。

---

**Q: 登録が途中で止まってしまいました**

A: CAPTCHA、二段階認証、または本人確認が必要な場合、Catashiro は自動で処理を中断します。
画面の案内に従って操作を完了してから「再開」をクリックしてください（[第6章](#6-自動化できない場面での手動対応)参照）。

---

**Q: このアプリをアンインストールしたらデータはどうなりますか？**

A: アプリを削除しただけではデータは残ります。完全に削除するには
[第10章](#10-アンインストールとデータの削除)の手順に従ってください。

---

**Q: 問題が発生した場合、どこに報告すればよいですか？**

A: [フィードバックガイド（docs/beta-feedback.md）](beta-feedback.md) を参照してください。
バグは GitHub Issues のバグ報告テンプレートから、改善提案はフィードバックテンプレートからご報告ください。
サポートバンドルの添付方法は第9章を参照してください。実際の個人情報・パスワード・カード番号・API キーは
絶対に記載しないでください。
