# Soroeru ユーザーマニュアル（Mac プライベートベータ版）

このマニュアルは、Soroeru の Mac プライベートベータ版を使って
「どのサイトに、どの個人情報を渡しているか」を確認する方向けの手順です。
開発者向けのビルド手順ではなく、DMG からのインストール、初回起動、CSV 取り込み、
Visibility 収集、開示台帳の見方を説明します。

Soroeru は、個人情報・オンラインアカウント・オンライン契約の領域で、
自分の判断を取り戻すためのローカルファースト・エージェンシーエンジンです。
ベータ版の最初の範囲は **Visibility（可視化）** です。一括更新、退会、新規登録は
後続スライスで扱います。

> **対象環境**: Apple Silicon Mac、macOS 14 Sonoma または macOS 15 Sequoia。
> ベータ版は未署名・未公証のため、初回起動時に Gatekeeper の確認が必要です。

> **安全のために**: 動作確認ではフェイクデータと自分で用意したテストアカウントを
> 使ってください。実サイトで試す場合も、必ず自分が所有するアカウントだけを対象にし、
> CAPTCHA、MFA、本人確認、ボット検出、レート制限、ペイウォール、アクセス制御の突破は
> 行わないでください。Soroeru もそれらを突破しません。

## 1. インストールと初回起動

### 1.1 アプリを入手する

招待された配布元から `Soroeru-<version>.dmg` を受け取ります。
DMG は Mac 用のインストーラー形式です。ベータ版を使うために Node.js やブラウザ拡張を
インストールする必要はありません。

### 1.2 インストールする

1. `Soroeru-<version>.dmg` をダブルクリックして開きます。
2. 表示された `Soroeru.app` を `/Applications` にドラッグします。
3. DMG を取り出します。

### 1.3 Gatekeeper の警告を解除して起動する

現在のベータ版は未署名・未公証です。初回起動時に macOS が警告を出す場合があります。

1. Finder で `/Applications/Soroeru.app` を右クリックします。
2. 「開く」を選びます。
3. 警告画面で、内容を確認して「開く」を選びます。

この操作は通常、初回のみ必要です。2 回目以降はダブルクリックで起動できます。

### 1.4 起動画面

起動すると、ウィンドウタイトルに **Soroeru**、サブタイトルに
「ローカルファースト・エージェンシーエンジン」と表示されます。
初回は暗号化ボールトの作成画面が表示されます。

## 2. 暗号化ボールトを作成する

ボールトは、Soroeru があなたの情報をローカルに暗号化して保存する場所です。
既定では次の場所に保存されます。

```text
~/Library/Application Support/Soroeru/vault.json
```

### 2.1 マスターパスフレーズを設定する

1. 「マスターパスフレーズを設定」にパスフレーズを入力します。
2. 8 文字以上であることを確認します。
3. 「作成して解錠」をクリックします。

パスフレーズは Soroeru の外へ送信されません。忘れると、リカバリーキーがない限り
保存した情報を復元できません。

### 2.2 リカバリーキーを作成する

ボールトを解錠すると、リカバリーキー未設定の案内が表示されます。

1. 「作成」をクリックします。
2. 表示されたリカバリーキーを安全な場所に保管します。
3. 「保管しました」をクリックします。

リカバリーキーは一度だけ表示されます。パスフレーズを忘れた場合の復旧手段なので、
パスワードマネージャーや紙など、あなたが管理できる場所に保存してください。

### 2.3 既存ボールトを開く

すでにボールトがある場合は、起動時に「マスターパスフレーズ」入力画面が表示されます。
リカバリーキーを設定済みなら「リカバリーキーで解錠」から開くこともできます。

## 3. CSV を取り込む

Soroeru は Google / Chrome パスワードマネージャーのエクスポート CSV から、
収集対象のサイトとログイン情報を取り込みます。

CSV のヘッダーは次の形式です。

```text
name,url,username,password,note
```

### 3.1 CSV を用意する

動作確認では、フェイクの `Google Passwords.csv` を用意してください。
実アカウントを使う場合は、必ず自分が所有するアカウントだけにしてください。

CSV にはログイン ID、パスワード、メモが含まれます。取り込みが終わったら、元の CSV は
自分で削除してください。Soroeru は安全のため自動削除しません。

### 3.2 取り込む

1. Soroeru を解錠します。
2. 「設定」タブを開きます。
3. 「CSV を取り込む」で「ファイルを選択」をクリックするか、CSV をドラッグ＆ドロップします。
4. 取り込み結果を確認します。

取り込み結果には、データ行数、取り込んだ認証情報、新規サイト、既存に一致した件数、
スキップ件数が表示されます。生のユーザー名、パスワード、note は表示されません。

## 4. Visibility 収集を実行する

Visibility 収集は、取り込んだサイトへ可視ブラウザでログインし、登録されている情報を
開示台帳に記録する機能です。

1. 「開示台帳」タブで収集したいサイトにチェックを入れます。
2. 必要なら「全てにチェックする」を使います。
3. 「選択したサイトを収集」をクリックします。
4. Soroeru が上から順に可視ブラウザを開き、保存済み認証情報でログインし、登録情報を収集します。
5. 収集が終わると、成功件数と要確認件数が表示されます。

収集中は「収集中...」と表示されます。CAPTCHA、MFA、確認コード、本人確認などのウォールに
当たった場合は自動で止まり、同じブラウザであなたに操作を渡します。

収集は、編集可能なフォーム欄、読み取り専用欄、ページ上に表示された登録情報を対象にします。
登録情報が別の「マイアカウント」「設定」ページにあるサイトでは、現時点では見つからない場合があります。

---

## 5. 開示台帳を見る

収集後、各サイトの「詳細」から開示台帳を確認できます。

台帳には次のような情報が表示されます。

| 表示 | 意味 |
| --- | --- |
| 開示 N | そのサイトから収集できた開示項目数 |
| 古い | Soroeru の正典値と異なる可能性がある項目 |
| 不明 | ハッシュのみなど、現在値との一致を判定できない項目 |
| 要確認 | ログイン未完了、情報なし、アクセス不能、ウォールなど確認が必要な状態 |
| ニュースレター / 継続課金 | サイトとの関係として検出された手がかり |

個別の値は既定でマスクされます。表示できる項目は「表示」を押し、マスターパスフレーズを
再入力してから一時的に確認します。確認後は「隠す」で再びマスクできます。

カードの CVV など最も機微な値は、台帳から表示できません。

### 5.1 新しい項目が見つかった場合

分類できない登録情報が見つかると、「新しい項目が見つかりました」と表示されます。
項目名を確認し、必要なら編集して「この項目として追加する」を押すと、次回以降の収集で
同じ種類の項目として扱われます。ここにも生の値は表示されません。

## 6. インサイトを見る

「インサイト」タブでは、開示台帳から得られた気づきが表示されます。

- **気づき（Reflection）**: 古い値、ニュースレター、課金、過剰開示、収集停止などを個別の観察として表示します。
- **横断フィルタ**: ニュースレターが有効なサイト、継続課金・無料トライアルのサイト、
  連絡先・カードが古いサイト、収集が止まっているサイトを横断的に見られます。

Soroeru はここで一括承認や一括実行を促しません。台帳とインサイトは、自分で判断するための材料です。

## 7. ウォールで手動対応する

次のような画面に到達した場合、Soroeru は自動化を止めます。

| ウォール | 例 |
| --- | --- |
| CAPTCHA | 画像選択、チェックボックス、Turnstile など |
| MFA / OTP | 認証アプリ、SMS、メールの確認コード |
| 本人確認 | 追加の身元確認、セキュリティ質問 |
| ボット検出 / レート制限 | 自動アクセス確認、しばらく待つよう求める画面 |
| ペイウォール / アクセス制御 | 支払い・権限がないと進めない画面 |

手順:

1. Soroeru の「ウォールの解決が必要です」という案内を確認します。
2. 表示中のブラウザで、必要な操作を自分で行います。
3. 完了したら「解決して再開」をクリックします。
4. そのサイトを飛ばす場合は「このサイトをスキップ」をクリックします。
5. まとめて止める場合は「一括収集を中止」をクリックします。

Soroeru はウォールを解決、突破、外注、隠蔽しません。

## 8. 保存ページから取り込む

自動収集がウォールやページ遷移で止まる場合、保存した HTML から登録情報を取り込めます。
この方法は、あなたが普段使うブラウザでログインし、登録情報ページを HTML として保存し、
Soroeru がローカルで解析するものです。

1. 対象サイトの「保存ページを取り込む」を開きます。
2. 必要なら「このサイトを開く」で既定ブラウザを開きます。
3. 自分でログインし、住所、会員情報、アカウント設定などのページを表示します。
4. ブラウザで「別名で保存」を選び、形式を「ウェブページ、HTML のみ」にして保存します。
5. Soroeru の「保存ページを選択」またはドラッグ＆ドロップで `.html` / `.htm` ファイルを取り込みます。
6. 取り込み後、元の HTML ファイルは自分で削除してください。

保存ページ取り込みは外部サイトへアクセスしません。保存した HTML をローカルで解析します。
実サイトのスクリーンショットや Cookie、トークンを Issue / PR / サポート連絡へ添付しないでください。

## 9. ロック、終了、再開

### 9.1 ロックする

画面右上の「施錠」をクリックすると、ボールトがロックされます。
再開するにはマスターパスフレーズ、または設定済みのリカバリーキーが必要です。

### 9.2 終了する

アプリを終了すると、Soroeru は可視ブラウザを閉じ、ボールトをロックします。
導出鍵や復号済みデータは保持されません。

### 9.3 再開する

次回起動時は、既存ボールトの解錠画面が表示されます。
アプリを削除してもボールトは自動では消えません。

## 10. アンインストールとデータ削除

### 10.1 アプリだけを削除する

1. Soroeru を終了します。
2. `/Applications/Soroeru.app` をゴミ箱に移動します。

この操作ではボールトは削除されません。

### 10.2 ボールトも削除する

保存データを完全に削除するには、次のフォルダを削除します。

```text
~/Library/Application Support/Soroeru/
```

Finder では「移動」→「フォルダへ移動...」から上記のパスを開けます。

> **注意**: この削除は元に戻せません。リカバリーキーを持っていても、削除したボールトは復元できません。

## 11. プライバシーとセキュリティ

- 個人情報、認証情報、開示台帳はローカルの暗号化ボールトに保存されます。
- ホスト型ボールト、分析、クラッシュレポートはありません。個人情報を含むテレメトリもありません。
- 現行の Mac 版では、ネットワーク通信は、ユーザーが操作する対象サイト、ユーザーが設定した AI
  プロバイダ、将来明示的に設計されたユーザー所有の暗号化ストレージに限定されます。Chrome 拡張版
  （開発中）の通信先は 11.1 を参照してください。
- 現行の Mac 版で AI モードを使う場合も、送るのはフォーム構造や規約テキストであり、生の個人情報値は
  送りません。
- サイトのパスワードとカードのセキュリティコード（CVV）は、ローカルの暗号化ボールトに保存しますが、
  どの AI にも送りません（対応中: Issue #572）。ログインなどでの入力は、AI を使わない Soroeru の
  プログラムが行います。
- CSV、保存 HTML、スクリーンショット、ログ、サポート用メモには秘密情報が含まれ得ます。
  共有前に必ず内容を確認してください。
- CAPTCHA、MFA、ボット検出、レート制限、ペイウォール、アクセス制御は手動ハンドオフ地点です。
  Soroeru は突破しません。

### 11.1 Chrome 拡張版（開発中）での情報の扱い

開発中の Chrome 拡張版では、情報を次の 4 種類に分けて扱います。

1. **ローカルに保存するもの**: 個人情報、パスワード、カード情報、開示台帳。Chrome 内に
   暗号化して保存し、Soroeru のサーバーには保存しません。
2. **共有するフォームの知識（個人情報を含まない）**: 「このサイトのこの入力欄は郵便番号」と
   いった、サイトの画面構造と項目の対応です。Soroeru の Google Cloud 上で利用者全員が共有し、
   精度を上げていきます。実際の値は含みません。
3. **改善用の動作データ（個人を特定する情報を含まない）**: 「どのサイトのどの版の対応で、
   成功・失敗・手動引き継ぎになったか」だけを送ります。利用者の識別子、URL の詳細、入力値、
   ページの内容は送りません。本番リリース前に、送信を止める設定を用意します。
4. **明示的に同意したときだけの Gemini による読み取り**: 1 と 2 で必要な情報を読み取れなかった
   ときに限り、処理を止めて確認画面を表示します。「今回だけ送信する」を選んだ場合に限り、
   そのページの必要な部分だけを Google の Gemini に送ります。パスワードやセキュリティコード
   などの秘密情報は伏せて送りません。断った場合は何も送りません。この送信内容は改善用データとして
   保存しません。

## 12. 現在の制限

- ベータ版は Mac 限定です。Windows、Linux、モバイルアプリは対象外です。
- ビルドは未署名・未公証です。自動更新もありません。
- 現在の主対象は Slice A Visibility です。一括更新、退会、新規登録は後続スライスです。
- フィールド検出は当面、日本語サイトを主対象にしています。
- ログイン後に登録情報ページへ自動遷移できないサイトでは、開示 0 件や要確認になる場合があります。
  その場合は保存ページ取り込みを使ってください。
- 実サイトの挙動は変わります。収集結果は「確定した真実」ではなく、自分で確認するための手がかりです。
