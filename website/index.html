Catashiro とは

Catashiro は、あなたの氏名・住所・電話番号・メールアドレス・クレジットカードなどの個人情報を あなたの Mac の中で暗号化して管理し、AI エージェントがあなたの代わりに Web サイトへの 会員登録・情報更新・退会を自動で完了させるローカルアプリです。

データはあなたの Mac から外に出ません。サーバーへの送信もテレメトリも一切なく、 ソースコードはすべて GitHub で公開されています。

🔑 新規登録を自動化

URL を渡すだけ。登録ページを探し、フォームを埋め、あなたの確認後に送信まで行います。

🔄 登録情報を一括更新

引っ越しや電話番号変更があったとき、複数サイトを選んでまとめて更新できます。

🛡️ ローカルで暗号化保管

AES-256-GCM + Argon2id でパスフレーズから鍵を生成。データはあなたの Mac だけに存在します。

📋 サイト登録一覧と退会管理

どのサイトに何を登録したかを一覧で確認。退会タスクも作成・管理できます。

⚠️ プライベートベータについて

このリリースは初期ユーザー約10名を対象とした Mac 専用プライベートベータです。 Windows・Linux・モバイルには対応していません。

  • アプリは 未署名・未公証です（Gatekeeper の警告が出ます。下記の回避手順を参照）。
  • 動作検証はまだ限定的です。重要な個人情報を試す前にテストデータで流れを確認してください。
  • バグや改善点は GitHub Issues または フィードバックガイド に記載の方法でお知らせください。

インストールと初回起動

  1. ZIP をダウンロードして展開する
    GitHub Releases の最新版 から Catashiro-mac-beta.zip をダウンロードし、ダブルクリックで展開します。
  2. Gatekeeper の警告を回避する（初回のみ）
    未署名のため、「開発元が確認できないため開けません」と表示されます。 ZIP を展開したフォルダで次のコマンドを実行してください。

    xattr -rc Catashiro.app

    その後、Finder から Catashiro.app を右クリック →「開く」→「開く」で起動できます。 詳しくは ユーザーマニュアル §2 を参照してください。
  3. マスターパスフレーズを設定する
    初回起動時に「ボルト初期設定」画面が表示されます。忘れると復元できないパスフレーズを設定し、 リカバリキーを安全な場所に保存してください。
  4. 個人情報と AI プロバイダを登録する
    「プロフィール」タブに氏名・住所などを入力します。次に「設定」タブで Anthropic または OpenAI の API キーを登録します（AI を使わない場合はスキップできます）。
  5. サイトを追加して自動登録を体験する
    「サイト」タブ →「サイトを追加」から URL を入力します。フォームが検出され、 内容確認のゲートを通過すると自動で登録が完了します。

詳しい操作は ユーザーマニュアル をご覧ください。

セキュリティとプライバシー

データはあなたの Mac から出ません。暗号化されたボルトファイルがローカルに存在するだけです。 Catashiro 自身のサーバーへのデータ送信・テレメトリは一切ありません。

  • 個人情報・カード番号・CVV・各サイトのパスワード・API キーはすべて AES-256-GCM で暗号化して保存。 鍵はアンロック中のみメモリ上に存在し、ロック時に破棄されます。
  • AI モデルにはフォームの構造や規約のテキストだけを渡し、実際の個人情報の値はローカルで入力します。
  • CAPTCHA・二段階認証・bot 検知は突破しません。 検知したら同じブラウザ画面であなたに引き継ぎ、完了後に再開します。
  • 最終送信はあなたの確認ゲートを通過した後にのみ行います。 高リスクな規約条項（自動課金、強制仲裁、第三者データ提供など）が見つかれば確認画面で警告します。
  • ソースコードは GitHub で公開されており、 誰でも確認・ビルドできます。

現時点での主な制限

  • Mac 専用（Apple Silicon のみ）。Windows・Linux・モバイルは対応外。
  • アプリは未署名・未公証のため、Gatekeeper の回避手順が必要です（初回のみ）。
  • 多言語フォーム対応は日本語が中心です。英語サイトは動く場合があります。
  • 決済・購入フロー（無料トライアル→課金のカード入力を除く）は対象外です。
  • SMS/OTP・CAPTCHA が必要なサイトは手動で解決する必要があります（引き継ぎ後に再開）。
  • 自動登録を利用規約で禁止しているサイトでは、入力まで行い最終ボタンはあなたが押します。
  • クラウドボルト同期・自動アップデートはまだありません。

フィードバック

バグ報告・改善要望は GitHub Issues へお願いします。実際の個人情報・パスワード・カード番号・API キーは絶対に記載しないでください。 ログを共有する場合は、アプリの「設定」→「サポートバンドルを書き出す」で生成した リダクション済みファイルを使用してください（個人情報の値は自動で除外されます）。

詳しい報告手順は フィードバックガイド（docs/beta-feedback.md） を参照してください。
